# HL2Minecraft (Half-Life 2 × Minecraft)

**HL2Minecraft** — это мод-композитор, объединяющий **Half-Life 2** и **Minecraft (Fabric 26.3)** в едином игровом процессе в реальном времени. Вы проходите сюжетные карты Half-Life 2 (или любые кастомные карты Source Engine), обладая всеми возможностями игрока из Minecraft: строительством и разрушением блоков, инвентарём, крафтом, полётом на элитрах, оружием, взрывами динамита, мобами и частицами, которые рендерятся напрямую в 3D-сцену DirectX 9 движка Source с честным перекрытием стенами (depth occlusion).

---

## ✨ Основные возможности

- **Прямой D3D9 3D-рендеринг внутри Half-Life 2:**
  - Чанки блоков Minecraft, 3D-модели мобов, предметов, снарядов, частиц, динамита (TNT) и руки/оружия от первого лица экспортируются через разделяемую память (`Local\HL2CraftShm`) и отрисовываются напрямую в Direct3D 9 поверх геометрии Half-Life 2 с использованием аппаратного буфера глубины (Z-buffer).
  - Стены и объекты Half-Life 2 корректно перекрывают блоки и мобов Minecraft.
- **Честная двусторонняя физика и коллизия:**
  - Установленные в Minecraft блоки создают физическую коллизию 1:1 в мире Half-Life 2, позволяя строиться под себя, возводить мосты и преграды для NPC.
  - Геометрия карт Half-Life 2 сканируется в реальном времени (`IEngineTrace`), поэтому стрелы, эндер-жемчуг, взрывы криперов/TNT, падающий песок и мобы Minecraft взаимодействуют со стенами и полом карт HL2.
  - Высота прыжка синхронизирована с Minecraft (~1.25 блока) без изменения гравитации мира HL2.
- **Синхронизация боя и NPC:**
  - Живые NPC и пропы из Half-Life 2 отображаются для ИИ и боевой системы Minecraft как сущности: по ним проходят удары мечом, выстрелы из лука/арбалета, урон от взрывов, а враждебные мобы Minecraft (криперы, зомби, скелеты) видят и атакуют NPC из Half-Life 2.
  - Получение урона и блокирование щитом синхронизированы между двумя играми.
- **Полноценный интерфейс и управление:**
  - HUD, хотбар, инвентарь (`E`), чат (`T`) и меню паузы Minecraft накладываются поверх окна Half-Life 2.
  - Поддержка полёта в креативе и планирования на **Элитрах** (с фейерверками) прямо по картам Half-Life 2.
  - Автоматическая очистка поставленных блоков и мобов при смене карты или перезагрузке сохранения в HL2 (с сохранением вашего инвентаря).

## 🚀 Быстрая установка (для игроков)

1. **Установите Minecraft 26.3 с Fabric Loader:**
   - Установите **Fabric Loader** (`0.19.5+`) и **Fabric API** для версии Minecraft `26.3` (например, через PrismLauncher).
   - Скачайте **`hl2craft-1.0.0.jar`** из раздела **[Releases](../../releases)** и поместите его в папку `mods` вашего инстанса Minecraft.
2. **Установите ReShade (с поддержкой Add-on) в Half-Life 2:**
   - Скачайте **ReShade 6.x with full add-on support** с официального сайта [reshade.me](https://reshade.me/#download).
   - В установщике ReShade выберите исполняемый файл `hl2.exe` в папке вашей игры Half-Life 2 (`Steam\steamapps\common\Half-Life 2\hl2.exe`).
   - Выберите графический API **DirectX 9** и завершите установку.
3. **Запустите Minecraft:**
   - При запуске Minecraft мод **автоматически** найдёт папку Half-Life 2, сам установит/обновит нативный аддон `HL2Minecraft.addon32` (он уже вшит внутрь `.jar` мода) и автоматически запустит Half-Life 2.
   - Если Half-Life 2 установлен в нестандартную папку, появится удобное внутриигровое окно настройки, где можно указать путь к `hl2.exe` в один клик.
4. **Играйте прямо в окне Half-Life 2!**
   - Загрузите любую карту или начните новую игру в Half-Life 2 — мир Minecraft автоматически синхронизируется с вашей позицией.

## 🎮 Управление (в окне Half-Life 2)

| Клавиша | Действие |
|---|---|
| `W`, `A`, `S`, `D` | Передвижение |
| `Пробел (Space)` | Прыжок (двойное нажатие — полёт в Креативе / раскрытие Элитр в воздухе) |
| `Left Shift` | Приседание (Красться) |
| `Left Ctrl` | Бег (Спринт) |
| `ЛКМ` | Атака мечом / Ломание блоков Minecraft |
| `ПКМ` | Установка блоков / Стрельба из лука / Щит / Использование предметов |
| `Колёсико мыши` / `1`–`9` | Выбор слота хотбара |
| `E` | Открыть инвентарь Minecraft |
| `Q` | Выбросить предмет |
| `F` | Переложить предмет во вторую руку (Offhand) |
| `T` / `/` | Открыть чат / Ввод команд Minecraft |
| `Esc` | Закрыть открытое меню Minecraft / Пауза |

## 🛠️ Сборка из исходного кода

Проект состоит из трёх частей:
- `protocol/` — общий заголовочный файл протокола разделяемой памяти (`hl2craft_protocol.h`).
- `hl2/` — 32-битный C++20 ReShade Add-on и D3D9-рендерер (`HL2Minecraft.addon32`) для Half-Life 2.
- `fabric/` — клиент-серверный мод Fabric для Minecraft 26.3 (Java 25).

### 1. Сборка C++ аддона (`HL2Minecraft.addon32`)
Требуется 32-битный компилятор MinGW-w64 (`g++.exe` с поддержкой `-m32` и `-std=c++20`, например из пакета `w64devkit`).
```bat
cd hl2
build.bat
```
Скрипт скомпилирует `HL2Minecraft.addon32` и автоматически скопирует его в `fabric/src/main/resources/assets/hl2craft/HL2Minecraft.addon32`.

### 2. Сборка Fabric-мода (`hl2craft-1.0.0.jar`)
Требуется JDK 25:
```bat
cd fabric
gradlew.bat build
```
Готовый файл мода (включающий внутри себя собранный `HL2Minecraft.addon32`) появится по пути:
`fabric/build/libs/hl2craft-1.0.0.jar`.
